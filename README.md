# Hola-Mundo

Aprender HTML, CSS y JS Basico - Expert

Proyecto para aprender HTML, CSS y JS de basico a experto (FUNDAMENTOS PARA WEB)

## Como abrir el curso

Desde la raiz del proyecto, en PowerShell:

```powershell
.\start.ps1
```

Eso abre el home (`index.html`) en el navegador, con enlaces a todas las clases.

Tambien puedes abrir `index.html` a mano.
